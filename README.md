# NEXUS

**Conectando ideas, creando futuro.**

Sitio web estático de temática tecnológica con una identidad futurista, minimalista y profesional. Paleta principal: azul eléctrico, negro y blanco.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable a móviles, tabletas y escritorio.
- `app.js`: filtros, buscador, menú móvil, tema claro/oscuro, lector de artículos y formulario demostrativo.

## Ejecutar localmente

Abre `index.html` en un navegador. No requiere instalación, servidor ni base de datos.

## Publicar con GitHub Pages

1. Abre el repositorio **Nexus** en GitHub.
2. Entra en **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama **main** y la carpeta **/(root)**.
5. Guarda los cambios. GitHub Pages publicará el sitio y mostrará su dirección.

## Nota

El formulario de suscripción es demostrativo: valida el correo en el navegador, pero no almacena ni envía datos. Para recibir suscripciones reales se necesita conectar un servicio externo o un backend.
